# 📊 Telco Customer Churn Analysis

## 🎯 Project Overview
Analysis of 7032 telecom customers to predict and understand customer churn using Machine Learning and Power BI.

## 📁 Files
- `churn_analysis.ipynb` — Complete Python analysis
- `churn_cleaned.csv` — Cleaned dataset
- `Churn_Analysis_Dashboard.pbix` — Power BI Dashboard

## 🔍 Key Findings
- Overall churn rate: **26.58%**
- Month-to-month customers churn the most
- Higher monthly charges correlate with churn
- New customers (low tenure) churn more

## 🤖 Machine Learning Models
| Model | ROC-AUC |
|-------|---------|
| Logistic Regression | 0.8357 |
| XGBoost | 0.8196 |
| Random Forest | 0.8142 |
